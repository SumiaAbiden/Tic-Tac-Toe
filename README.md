# Tic Tac Toe Game (p5.js)

This project is a browser-based Tic Tac Toe (XOX) game developed using JavaScript and the p5.js library. It features interactive gameplay, custom player names, audio effects, a scoring system, and visual feedback such as a mouse trail and winner lines.

## Features

- Two-player mode with custom name input
- Visual mouse trail effect
- Sound effects for move, win, and tie
- Score tracking with a scoreboard at the top
- Turn counter and current player display
- Winning line drawing (horizontal, vertical, diagonal)
- Automatic board reset after each round

## How to Run

1. Include the p5.js library in your HTML file.
2. Link the main script file (`sketch.js`) and make sure all audio files are located in an `assets/` folder.
3. Open the HTML file in a web browser.
4. Enter player names when prompted and start playing.

## Controls

- Click an empty cell to make a move.
- Players alternate turns automatically.
- The board resets automatically after a win or tie.

## Dependencies

- [p5.js](https://p5js.org/)
